初识EJS

2026/6/10 全栈开发 后端 EJS JavaScript

在设置博客的文章隐藏部分时遇到了接触到了这类文件，顺便详细了解一下。

EJS是干什么的

纯 HTML 文件是“死”的（静态的）。如果你有 100 篇博客文章，你肯定不想手动写 100 个长得一模一样的 HTML 文件。

ejs的工作原理是让开发者只需要写一个包含网页骨架的 .ejs 文件作为“模板”。当你运行 hexo g 的时候，Hexo（基于 Node.js）就会把你的 Markdown 文章数据（标题、时间、内容）塞进这个模板里。EJS 会执行里面的 JavaScript 逻辑（比如循环、条件判断），最后“印”出无数个纯静态的 .html 文件，供浏览器读取。

EJS的核心语法

在 EJS 中，最核心的语法就是标签：

<% … %>：逻辑标签。里面写纯 JavaScript 代码（如 if 判断、for 循环），它只负责默默在后台执行，不会在网页上输出任何内容。

<%= … %>：转义输出标签。把 JS 变量的值打印到 HTML 里（比如 <%= post.title %> 会变成 我的文章标题）。它会把特殊字符变成安全字符，防止代码注入。

<%- … %>：非转义输出标签。也是输出变量，但它保留原汁原味的 HTML 标签。比如文章的正文本身就包含 <strong> 或 <p> 等 HTML 标签，就必须用 <%- %>，否则标签会被当成纯文本显示出来。
