Hexo常见操作整理

2024/10/1

Welcome to Hexo! This is your very first post. Check documentation for more info. If you get any problems when using Hexo, you can find the answer in troubleshooting or you can ask me on GitHub.

快速开始

Create a new post

$ hexo new "My New Post"

More info: Writing

Run server

$ hexo server

More info: Server

Generate static files

$ hexo generate

More info: Generating

Deploy to remote sites

$ hexo deploy

More info: Deployment

以上，就是hexo 自带的hello world的内容

设置文章资源文件夹

在根目录的_config.yml中修改如下内容：

post_asset_folder: true
marked:
  prependRoot: true
  postAsset: true

这样就会在 new 的时候自动生成一个同名文件夹，文章里需要插入的图片（或是其他资源），都可以放在这个文件夹下，避免混乱。

首页文章排序

在 Front-Matter 里设置 pinned 作为置顶参数，越大越靠前，默认为 0。

设置隐藏文章

在 Front-Matter 里设置 hide: true

然后修改MyBlog\themes\particlex\layout\posts.ejs为如下内容

<%
    // 1. 提取所有非隐藏的文章到一个纯净的普通数组中
    let valid_posts = [];
    site.posts.forEach(function(post) {
        if (!post.hide) {
            valid_posts.push(post);
        }
    });

    // 2. 对纯数组进行排序（按置顶权重降序，再按时间降序）
    valid_posts.sort(function(a, b) {
        let x = a.pinned || 0;
        let y = b.pinned || 0;
        if (x === y) {
            return b.date - a.date;
        }
        return y - x;
    });

    // 3. 计算分页并截取当前页需要显示的文章
    let current = (page.current - 1) * config.index_generator.per_page;
    let display_posts = valid_posts.slice(current, config.index_generator.per_page + current);
%>
<% display_posts.forEach(function(post) { %>
<div class="post">
    <a href="<%- url_for(post.path) %>">
        <h2 class="post-title"><%= post.title %></h2>
    </a>
    <div class="category-and-date">
        <% if (post.categories.data.length !== 0) { %>
        <span class="category">
            <a href="<%- url_for(post.categories.data[0].path) %>">
                <span class="icon">
                    <i class="fa-solid fa-bookmark fa-fw"></i>
                </span>
                <%= post.categories.data[0].name %>
            </a>
        </span>
        <% } %>
        <span class="date">
            <span class="icon">
                <i class="fa-solid fa-calendar fa-fw"></i>
            </span>
            <%- date(post.date, "YYYY/M/D") %>
        </span>
        <% if (theme.crypto.enable && typeof post.secret !== "undefined") { %>
        <span class="special">
            <i class="fa-solid fa-lock fa-fw"></i>
        </span>
        <% } %>
        <% if (typeof post.pinned !== "undefined") { %>
        <span class="special">
            <i class="fa-solid fa-grip-vertical fa-fw"></i>
        </span>
        <% } %>
    </div>
    <div class="description">
        <div class="content" v-pre>
            <% if (typeof post.description !== "undefined") { %>
            <%- markdown(post.description) %>
            <% } else if (post.excerpt) { %>

            <%- post.content %>
            <% } %>
        </div>

        </span>
        <% } %>
        <% let prev; %>
        <% post.tags.data.forEach(function(tag) { %>
        <span class="tag">
            <%
                const colors = theme.colors.filter(function(color) { return color !== prev; });

            %>

        </span>
        <% }); %>
    </div>
    <a href="<%- url_for(post.path) %>" class="go-post">阅读全文</a>
</div>
<% }); %>
